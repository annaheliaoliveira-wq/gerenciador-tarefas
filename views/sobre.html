Sobre o Projeto

Projeto prático desenvolvido para a disciplina de Desenvolvimento Web III do curso Superior de Tecnologia em Análise e Desenvolvimento de Sistemas (ADS).

Objetivos de Aprendizagem

  • Compreender o funcionamento de frameworks do lado do servidor (Server-side).
  • Estruturar rotas HTTP (GET e POST) com Express.
  • Processar dados submetidos via formulários HTML.
  • Implementar middlewares para registro de logs e tratamento de rotas não definidas (404).
  • Servir páginas HTML estáticas e respostas geradas dinamicamente no backend.

Tecnologias Utilizadas

Node.js

Ambiente de execução JavaScript no lado do servidor.

Express

Framework web para Node.js.

HTML5 & CSS3

Estruturação semântica e estilização responsiva.
